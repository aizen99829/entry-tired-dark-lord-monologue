After nine hundred years of ruling the mountains, the Dark Lord is not angry — he is tired. The skulls are still here, the traps are still resetting, and the minions have unionized. This monologue is his weary surrender: one evening, some tea, and no one calling him "my lord."

Run it with `node main.ts`.
